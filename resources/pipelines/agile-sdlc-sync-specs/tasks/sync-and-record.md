**Goal:** Apply deterministic non-overlapping living-spec updates one target at a time, recording each target immediately and resuming safely after interruption.

**Scope:** This task updates only the exact approved existing artifacts and sections, persists per-target progress, and appends each sync event immediately. It is resumable, not transactional. It must not edit source or tests, invent history, delete evidence, overwrite deferred scope or unresolved questions, deploy, publish, merge, or continue when unapproved.

**Verification / Definition of Done:**
- [ ] Status was loaded from SpecX run context for this run, and the task stopped unless it was approved.
- [ ] The exact Delivery Record, matching-revision event, and required verification history were reevaluated before editing.
- [ ] Upstream failed, blocked, needs_input, and missing/unreadable state mapped without collapsing outcomes.
- [ ] All target paths were preflighted against the implementation permitted boundary before the first edit; overlap stopped blocked without mutation.
- [ ] Updates were limited to criteria the record shows were met and decisions the record shows shipped.
- [ ] Per-target progress was persisted before mutation; targets were processed one at a time, and each completed update gained its own append-only sync event immediately.
- [ ] Resume reconciliation compared the intended section change, actual target, and existing event without repeating a completed edit or event; ambiguous or mismatched partial state blocked and named the target.
- [ ] Exact existing target artifact ids/titles and sections were updated in place without relocation; prior evidence was preserved, and deferred scope and unresolved questions were not overwritten.
- [ ] An empty living-spec list completed as a done no-op and appended one no-op sync event.
- [ ] Application source and tests were not edited. Nothing was deployed, tagged, published, or merged. No other pipeline was started.
- [ ] The handoff is at most five lines: outcome, decision needed, document written, evidence, and next action.
