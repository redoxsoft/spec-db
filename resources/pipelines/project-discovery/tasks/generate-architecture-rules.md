**Goal:** Capture maintainability and implementation conventions separately from stack selection for every project.

**Scope:** Create or update SpecX spec `${PROJECT_NAME} - Architecture Rules` using the required SpecX spec Discovery Rules. Do not ask for permission, alter the locked stack, or add feature requirements. Do not write local markdown rule files.

**Definition of Done:** The architecture-rules SpecX spec is written and validated, covers the selected stack and requirements, and is ready for Scaffolding and Building.

Actions:

- Resolve SpecX spec Discovery Rules before writing (hard stop if missing).
- Always create or update SpecX spec titled `${PROJECT_NAME} - Architecture Rules` with `artifact_type: architecture_rules`.
- Keep these rules separate from SpecX spec `${PROJECT_NAME} - Decision Matrix`.
- This task is mandatory and has no opt-out.
