**Instructions:**

1. Expose concise state while working: `drafting`, `waiting` for a newly discovered consequential decision, or `blocked` when a required dependency is unavailable.
2. Reload the complete Task 1 **Persisted handoff**, including the approved mode and each separate output placement. For each artifact, name every missing field of that disposition and stop `blocked`: an update needs the artifact id, current folderId, and informational folderPath; a create needs the approved folderPath. Stop unless status is approved. Do not reconstruct state from conversation or re-ask an approved choice.
3. For each output, load only its own persisted placement; never recompute, share placements, list folders, or relocate. For an update, call `document_read` with `documentId` set to the persisted artifact id, then `document_update` that same `documentId` so the draft stays in the document's current folder. If the reread `folderId` differs from the persisted folderId, include a concise advisory and still write there. If `document_create` or the template cannot be made available, stop `blocked`.

7. Emit at most five lines labeled Outcome, Decision, Artifact, Evidence, and Next action. Use `done`, `failed`, `needs_input`, or `blocked` truthfully. Artifact names each exact document and informational folder path; include a persisted placement advisory only when present. Evidence concisely names the source and repository facts used and gives provenance only for material decisions or assumptions. Do not modify application source code or create another artifact.
