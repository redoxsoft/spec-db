**Goal:** Prove that the proposed milestone sequence is complete, ordered, and executable.

**Scope:** Validate coverage, dependency direction, cycles, eligibility, definitions of done, and deployment scope using SpecX spec Planning Rules. Do not repair implementation defects or silently change requirements.

**Definition of Done:** All validation checks pass; the first eligible milestone is unambiguous; all failures are either corrected in the plan or reported as blockers.

Actions:

- Check every in-scope requirement is covered.
- Check dependencies point only to earlier milestones and no cycles exist.
- Check the first pending milestone is unambiguous.
- Check every milestone has a verifiable definition of done.
- Exclude deployment or production work unless explicitly requested.
